CodeStart Guide - Site Plan

Site Name

CodeStart Guide

The name "CodeStart Guide" reflects the purpose of helping beginners take their first steps into programming. It represents a starting point for learning coding and exploring technology careers.

Site Purpose

The purpose of this website is to help programming beginners understand what programming is, choose a programming language to start learning, explore programming careers, discover project ideas, and find useful learning resources.

Scenarios

  • Which programming language should I learn first?
  • What beginner projects can help me practice programming?
  • What career opportunities are available in software development?

Color Schema

  • Blue (#2563EB): Used for headings, buttons, links, and accents.
  • Light Gray (#F1F5F9): Used for page backgrounds and content sections.
  • Dark Gray (#111827): Used for body text.

Typography

Inter will be used throughout the website because it is modern, clean, and easy to read. Headings will use a bold weight, while body text will use a regular weight.
